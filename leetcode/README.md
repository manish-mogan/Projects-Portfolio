# LeetCode (Python)

This folder contains a topic-organized set of LeetCode problem stubs.

## Structure

- Each problem lives under: `leetcode/<topic>/<id>-<slug>/`
- Each problem folder contains:
  - `problem.md` — a short, original summary + your notes
  - `solution.ipynb` — a notebook stub to implement later

## Topics

Topics are grouped for navigation (e.g., `arrays_hashing`, `two_pointers`, `stack_queue`, `dynamic_programming`, etc.).

## Workflow

1. Open a problem folder.
2. Read `problem.md` and fill in the **Notes** section (approach, edge cases, complexity).
3. Implement the solution in `solution.ipynb`.

## Naming

Folders are named with a 4-digit id prefix (e.g., `0001-...`) to keep problems sorted.
